# Todo App

A simple Todo application built using HTML, CSS, and JavaScript.

It allows users to add, complete, and delete tasks with data saved in local storage.

---

## Features

- Add new tasks  
- Mark tasks as completed  
- Delete tasks  
- Data persists after refresh (local storage)  
- Clean and modern UI  

---

## Tech Stack

- HTML  
- CSS  
- JavaScript  

---

## How to Run

1. Open index.html  
2. Run in browser  
3. Start adding tasks  

---

## Future Improvements

- Edit task feature
