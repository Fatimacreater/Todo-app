# 📝 Todo App

A clean and simple Todo application built using HTML, CSS, and JavaScript.

It helps users manage daily tasks with features like adding, completing, and deleting tasks. Data is stored in the browser using local storage.

---

## 🔗 Live Demo

👉 https://fatimacreater.github.io/Todo-app/

---

## ✨ Features

- Add new tasks  
- Mark tasks as completed  
- Delete tasks  
- Data saved using local storage  
- Clean and responsive UI  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript (Vanilla)

---

## 📸 Preview

A modern card-based todo interface with gradient background and smooth interactions.

---

## 🧠 What I Learned

- DOM manipulation  
- Event handling in JavaScript  
- Working with arrays  
- Using local storage  
- Building interactive UI  

---

## 🚀 Future Improvements

- Edit tasks  
- Filters (All / Active / Completed)  
- Drag and drop tasks  
- Animations for better UX  

---
